Confidentialité

Boomerang est conçu pour garder le moins de données possible : aucun nom, aucun compte, aucune publicité. Un avatar (un animal et une couleur) et un code suffisent.

Ce qui reste sur l'appareil

  • L'avatar de chaque élève, et une empreinte de son code secret (jamais le code lui-même).
  • Les réponses aux cartes, pour savoir quand les revoir, et le nombre de séances, pour faire pousser la plante.
  • Les réglages : police, taille du texte, voix.
  • Le code de la classe, et les paquets de révision déjà ouverts, pour travailler sans connexion.

Ce qui est copié sur le serveur

Quand l'appareil utilise un code de classe, une copie part sur un serveur situé en Europe (Supabase, à Francfort) pour que l'élève retrouve son travail en classe et à la maison :

  • le code de la classe et l'avatar ;
  • une empreinte du code secret de l'élève, jamais le code en clair ;
  • le nombre de séances (la plante), sans date ni lieu ;
  • l'état des cartes (à revoir ou sues) ;
  • côté enseignant : une empreinte du code enseignant de la classe et les paquets de révision publiés ;
  • des informations techniques qui bloquent un code pendant une heure après 5 essais faux.

Rien d'autre : ni nom, ni adresse, ni photo, ni position. Les réglages restent sur l'appareil. La lecture à voix haute utilise la voix de l'appareil : aucun texte n'est envoyé.

Combien de temps

Toutes les données du serveur sont effacées automatiquement chaque année, le 31 août.

Comment effacer

  • En classe : l'enseignant peut effacer les données d'un élève, sur l'appareil et sur le serveur.
  • À la maison : supprimer Boomerang de l'écran d'accueil efface ce qui est sur l'appareil.

Cookies et traceurs

Aucun cookie, aucun traceur, aucune mesure d'audience, aucune publicité. Aucune police ni aucun script n'est chargé depuis un site extérieur.
