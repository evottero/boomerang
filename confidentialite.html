Confidentialité

Boomerang garde le moins de données possible. Pas de nom, pas de compte, pas de publicité : un avatar (un animal, une couleur) et un code à 4 chiffres suffisent.

Sur l'appareil

L'avatar et une empreinte du code (jamais le code lui-même), l'état des cartes, le nombre de séances qui fait pousser la plante, les réglages d'affichage et de voix. S'y ajoutent le code de la classe et les paquets déjà ouverts, pour réviser sans connexion.

Sur le serveur, uniquement avec un code de classe

Pour que l'élève retrouve son travail en classe et à la maison, une copie est conservée sur un serveur en Europe (Supabase, Francfort) : le code de la classe, l'avatar, l'empreinte du code, l'état des cartes et le nombre de séances, sans date ni lieu. Côté enseignant : une empreinte de son code et les paquets publiés. Après 5 codes faux, l'avatar est bloqué une heure.

Aucun nom, aucune adresse, aucune photo, aucune position. La lecture à voix haute utilise la voix de l'appareil : aucun texte n'est envoyé.

Durée

Toutes les données du serveur sont effacées automatiquement chaque 31 août.

Effacer les données

L'enseignant peut effacer les données d'un élève, sur l'appareil et sur le serveur. À la maison, supprimer Boomerang de l'écran d'accueil efface ce qui se trouve sur l'appareil. Pour exercer vos droits, consultez les mentions légales.

Cookies et traceurs

Aucun cookie, aucun traceur, aucune mesure d'audience. Aucune police ni aucun script n'est chargé depuis un site extérieur.
