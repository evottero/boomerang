Données personnelles

Responsable du traitement : Eric Vottero.
Données conservées : le code de la classe, l'avatar choisi, une empreinte chiffrée du code personnel (jamais le code lui-même), l'état des cartes de révision et le nombre de séances. Aucun nom, aucune adresse e-mail, aucune donnée de connexion n'est demandé.
Finalité : permettre à l'élève de retrouver sa progression d'un appareil à l'autre.
Durée de conservation : toutes les données sont effacées automatiquement chaque 31 août.
